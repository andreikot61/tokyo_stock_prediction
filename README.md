# Прогнозирование доходности акций на токийской фондовой бирже

## Описание проекта
Проект посвящён анализу исторических данных фондового рынка и прогнозированию доходности акций. Работа выполнена на основе датасета соревнования Kaggle JPX Tokyo Stock Exchange Prediction.
Основная цель — исследовать динамику цен акций, отранжировать акции в портфеле по доходности и как следствие реализовать стратегии long и short для нескольких первых и последних соответственно. 

## Цели проекта
- Провести исследовательский анализ данных (EDA).
- Изучить динамику цен и доходности отдельных акций.
- Построить признаки на основе исторических наблюдений.
- Обучить модель градиентного бустинга CatBoost.
- Оценить качество модели на отложенном временном периоде.

## Данные
Используются исторические данные об акциях, торгующихся на Токийской фондовой бирже.
Основные поля:
- `Date` — дата торгов.
- `SecuritiesCode` — идентификатор акции.
- `Open`, `High`, `Low`, `Close` — цены открытия, максимальная, минимальная и закрытия.
- `Volume` — объём торгов.
- `Target` — целевая переменная для обучения модели.

## Этапы работы
### 1. Исследовательский анализ данных
- Изучение структуры и качества данных.
- Анализ динамики цен.
- Расчёт доходности акций.

### 2. Генерация признаков
На основе исторических данных формируются признаки:
- доходность акций;
- лаговые значения доходности;
- скользящие средние;
- скользящая волатильность;
- календарные признаки.
При построении признаков учитывается временной порядок наблюдений, чтобы избежать использования информации из будущего.

### 3. Обучение модели
В качестве основной модели используется **CatBoost Regressor** — алгоритм градиентного бустинга над решающими деревьями.
Данные разделяются на обучающую и валидационную выборки по времени. Это позволяет оценить качество модели на более позднем периоде без случайного перемешивания временных наблюдений.

### 4. Оценка качества
Результаты на валидационном периоде:
- **Средняя дневная доходность спреда:** 0.3631
- **Стандартное отклонение дневной доходности спреда:** 2.9147
- **Коэффициент Sharpe:** 0.1246
- **Количество торговых дней:** 225
